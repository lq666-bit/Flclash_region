<p align="center">
**FlClash 地区分流规则配置**
</p>

基于 FlClash 的地区分流配置，根据访问目标所属地区，将网络流量分配至对应的策略组，实现更加清晰、灵活的代理管理。

✨ 项目简介

本项目主要用于 FlClash 的地区分流，将不同地区的网络流量划分至对应的策略组。

通过地区规则匹配，让不同地区的网站和服务自动选择相应的代理策略，减少手动切换节点的操作。

🚀 主要功能
地区分流：根据目标地址所属地区匹配对应规则。
策略组管理：按照地区划分代理策略组。
自动匹配：根据规则自动选择对应的策略组。
灵活配置：可根据个人需求调整地区规则和策略组。
📌 使用说明
下载或复制本仓库提供的配置文件。
打开 FlClash。
导入对应配置文件。
根据自己的节点情况调整策略组。
启用配置即可使用地区分流规则。
⚙️ 自定义配置

可以根据实际需求修改地区规则及对应策略组：

添加或删除地区规则。
调整地区对应的策略组。
修改策略组中的节点选择方式。
根据实际使用情况调整规则优先级。

注意：策略组名称需要与配置文件中的实际名称保持一致。

⚠️ 注意事项
使用前请确认配置文件与当前 FlClash 版本兼容。
请确保对应策略组中存在可用节点。
地区规则的匹配效果取决于规则集及其更新情况。
如果修改了策略组名称，需要同步调整相关规则。
